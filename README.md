# AI Behavioral Interview Coach

A data-driven web application designed to bridge the gap between technical skills and interview performance. 

##  Overview
Many students struggle to articulate their experiences under pressure. This project provides a "safe space" to practice by analyzing typed responses and providing instant, visual feedback on performance metrics.

##  Key Features
- **Real-time NLP Analysis:** Evaluates sentence structure and identifies "weak" vocabulary or excessive filler words (e.g., "like," "actually," "um").
- **STAR Method Verification:** Uses keyword heuristics to ensure the user is following the *Situation, Task, Action, Result* framework.
- **Dynamic Visualization:** Features an interactive Radar Chart (using Chart.js) to show the balance between Clarity, Confidence, Structure, and Impact.
- **Actionable Coaching:** Generates specific tips based on the user's unique score profile.

##  Tech Stack
- **Frontend:** React & Tailwind CSS
- **Visualization:** Chart.js
- **Logic:** Heuristic-based Natural Language Processing (JavaScript)

##  What I Learned
Through this project, I explored how to translate abstract communication goals into quantifiable data. I focused on:
1. **User Experience (UX):** Creating a clean, non-intimidating interface for a high-stress task.
2. **Algorithm Design:** Designing logic to detect speech patterns and structural markers in text.
3. **Data Visualization:** Determining the most effective ways to show performance trends to a user.
